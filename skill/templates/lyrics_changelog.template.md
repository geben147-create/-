# 가사 작업 이력 (인간 기여 기록)

원칙: **내가 먼저 쓰고 → AI에게 대안을 요청하고 → 내가 고른 뒤 다시 고친다.**
AI가 초안을 다 쓰고 단어 몇 개만 바꾸면 "AI 생성 가사"에 가깝습니다.

## 파일 규약
```
LYRICS/
├─ 00_my_draft_YYYYMMDD.txt      내가 먼저 쓴 초안
├─ 01_ai_suggestions_YYYYMMDD.txt AI에게 받은 대안 (원문 그대로)
├─ 02_my_revision_YYYYMMDD.txt    내가 고른/고친 버전
├─ 03_final_human.txt             최종본
└─ CHANGELOG.md                   이 파일
```

## 기록 형식

| 시각 | 무엇을 | 누가 |
|---|---|---|
| 09:02 | 1절 4줄 작성 | 나 |
| 09:07 | "리듬에 맞는 대안 5개, 의미는 유지" 요청 | AI |
| 09:13 | 3번·5번을 섞어 2행 재작성 | 나 |
| 09:20 | 후렴 2줄 전체 교체 | 나 |

## 유통사 공시와의 관계
- 가사를 **AI가 작성**했다면 공시에서 "가사(lyrics)" 항목에 AI를 표시해야 합니다.
- 맞춤법 교정·표현 다듬기 수준은 보통 "AI 생성 가사"로 보지 않지만, 판단이 갈릴 수 있으니
  이 이력 자체를 남겨두는 것이 가장 안전합니다.
