# 9컷 템플릿 — 주제만 갈아끼우는 법

이 릴에서 재사용되는 자산은 **문구가 아니라 구조**입니다.
아홉 장의 순서와 각 장이 맡은 일은 주제가 바뀌어도 그대로입니다.

    문제 → 원인 → 반전 → 해결 → 체크리스트 → CTA

돈, 건강, 부동산, 공부법, 육아, 장비 리뷰 — 사람이 "왜 이런지 모르겠는데
답답한" 주제라면 전부 이 뼈대에 얹힙니다.

## 각 컷이 맡은 일

| 컷 | 역할 | 길이 | 이 장에서 시청자가 얻는 것 | 흔한 실패 |
|----|------|------|---------------------------|-----------|
| S1 | 훅 | 3.5s | "내 얘기다" | 설명부터 시작 |
| S2 | 문제 | 3.0s | 증상의 이름 | 원인을 여기서 말해버림 |
| S3 | 원인 1 | 3.0s | 첫 번째 이유 | 두 개를 한 장에 욱여넣음 |
| S4 | 원인 2 | 3.0s | 두 번째 이유 | 앞과 같은 말 반복 |
| S5 | 반전 | 3.0s | "그럼 내가 알던 게 틀렸네" | 반전이 없어 밋밋 |
| S6 | 해결 1 | 3.0s | 오늘 할 행동 | 추상적 조언 |
| S7 | 해결 2 | 3.0s | 두 번째 행동 | 세 개 이상 나열 |
| S8 | 체크 4 | 5.0s | 저장할 이유 | 5개 이상 — 안 읽힘 |
| S9 | CTA | 3.5s | 다음 행동 | 팔로우만 요구 |

합계 30.0초. 전환 0.2초 × 8을 빼면 완성본은 28.4초입니다.

**S5가 이 구조의 심장입니다.** 문제·원인·해결만 있으면 그냥 정보이고,
반전이 있어야 "저장"이 나옵니다. 반전이 안 떠오르는 주제라면 그 주제는
아직 영상으로 만들 준비가 안 된 것입니다.

## 만드는 순서

1. **복사**

       cp scenes.template.json scenes_내주제.json

2. **`{{ }}` 채우기.** 규칙 셋:
   - 한 장에 한 가지만. 두 개면 컷을 나눕니다.
   - 두 줄 이내, 한 줄 12자 안팎. 길면 화면에서 못 읽습니다.
   - **측정 안 한 수치는 쓰지 않습니다.** 근거 있는 값만, 없으면 원리로.

3. **장르 팩 지정.** `genre_pack` 에 `packs/genre/` 폴더명을 넣습니다.
   컷 길이·시선·필수 샷·금지가 거기서 결정됩니다.

       python ../pipeline/validate.py --manifest scenes_내주제.json

4. **이미지 9장.** 각 컷의 `image_prompt` 를 씁니다. 빠지면 안 되는 두 가지:

       ...상단 절반은 비운다(자막 자리)..., no text, no letters, no numbers

   **견적이 0인지 먼저 확인하고 생성합니다.** 0이 아니면 멈춥니다.

5. **조립.** `studio.html` (브라우저) 또는 `build_video.py` (파이썬).

       python build_video.py --scenes scenes_내주제.json --out out/내주제.mp4

## 주제별로 바꿔야 하는 것

| 주제 | 장르 팩 | 화면 주체 | 훅의 각도 |
|------|---------|-----------|-----------|
| 돈·경제 | `finance_explainer` | 데이터·사물 | 손실 회피 |
| 건축·실측 | `arch_technical` | 구조물·단면 | 안 보이는 내부 |
| 사건·기록 | `documentary` | 장소·자료 | 알려지지 않은 사실 |
| 리액션·유머 | `comedy_character` | 표정 | 공감 |
| 짧은 훅 | `shorts_retention` | 변화·결과 | 결과 먼저 |

바꾸지 않는 것: 아홉 장의 순서, 30초 구성, 상단 절반 비우기,
자막은 코드로 얹기, 견적 0 확인.

## 언어 추가

`scenes_ja.json` 이 예시입니다. 복사해서 문구만 번역하고 `font` 를 바꿉니다.

| 언어 | font |
|------|------|
| 한국어 | `Noto Sans KR` |
| 일본어 | `Noto Sans JP` |
| 영어 | `Noto Sans` 또는 아무 산세리프 |

**폰트를 안 바꾸면 글자가 □ 로 나옵니다.** 한국어 폰트에는 가나가 없고,
일본어 폰트에는 한글이 없습니다. 이미지는 그대로 재사용합니다 —
글자가 이미지 안에 없기 때문에 언어만 갈아끼우면 됩니다.

## 훅만 바꿔서 A/B

`scenes.json` 의 `hook_variants` 에 여섯 가지가 들어 있습니다.
S1 문구만 바꾸고 나머지 여덟 장은 그대로 두면, 같은 영상으로 훅만
시험할 수 있습니다. `studio.html` 상단에서 고르면 즉시 반영됩니다.
