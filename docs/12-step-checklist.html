🩷 프롬프트 3 · 허밍을 작곡으로
내가 부른 허밍 파일이야. BPM은 [112] 이고 키는 [Ebm] 이야. 1. Basic Pitch로 악보(MIDI)로 바꿔줘 2. 박자에 맞게 정렬하되 ⚠️ 내가 부른 음정은 바꾸지 마 3. 음정이 애매한 노트는 "이거 맞아?"로 표시만 하고 ⚠️ 자동으로 고치지 마 4. 이 악보를 피아노 / 스트링 / 신스 리드 세 가지로 연주시켜서 들려줘 5. 리듬 변형안을 A / B / C 세 개 만들어줘 - 리듬, 음 길이, 쉼표 위치가 서로 달라야 해 6. ⚠️ 아직 아무것도 확정하지 마. 내가 고를 때까지 멈춰 내 원본 허밍 WAV랑 변환된 MIDI 둘 다 따로 보관해줘.
📌

드럼 오디오도 같이 처리합니다 — 박자 검출해서 타이밍·강약 정리. 베이스는 리듬·음 길이·세기 정리 + 옥타브 변형안까지 만듭니다.

제가 만든 A·B·C를 듣고 이 정도만 말씀하시면 됩니다.

🩷 이렇게만 말하면 됩니다
B가 제일 좋다. 근데 4번째 음은 한 음 내려줘. 드럼은 A로 하고 후렴 마지막 두 마디는 좀 세게. 베이스는 C인데 마지막 음은 길게 끌어줘.

가수들이 실제로 쓰는 과정을 그대로 돌립니다. 테이크 컴핑 → 노이즈 제거 → 음정 보정 → 타이밍 정렬 → 디에서 → EQ·컴프 → 하모니 생성 → 믹스 → 마스터링.

🩷 프롬프트 4 · 보컬 튜닝
보컬 테이크 3개야. 반주는 [파일명] 이고 BPM은 [112] 야. 1. 세 테이크에서 가장 좋은 구간만 골라서 이어붙여줘 (컴핑) - 어느 테이크의 어느 구간 썼는지 목록으로 알려줘 2. 노이즈 제거 (원음 뭉개지지 않는 선에서만) 3. Graillon 3로 음정 보정 ⚠️ 자연스럽게. 로봇처럼 되지 않게 4. 박자에 맞게 정렬하되 ⚠️ 내 부르는 느낌은 살려줘 5. 디에서, EQ, 컴프레서 6. 후렴에만 3도 / 5도 하모니 만들어서 얹어줘 7. ⚠️ 원본 테이크는 절대 덮어쓰지 말고 그대로 보관 보정 전 / 보정 후를 비교해서 들을 수 있게 두 파일로 뽑아줘.
🩷 프롬프트 5 · 마스터링 + 제출 준비
최종 믹스해서 유통용으로 뽑아줘. 1. 전체 믹스 밸런스 맞추기 2. 음량 정규화 (스트리밍 기준) 3. 스테레오 FLAC, 16bit, 44.1kHz로 출력 4. 검사해줘: - 클리핑 있는지 - DC 오프셋 - 트루피크 - 앞뒤 무음이 8초 넘는지 그리고 제작 기록을 만들어줘: - 사용한 툴이랑 버전 전부 - AI가 관여한 요소 (가사 / 보컬 / 악기연주 / 작곡 중 어디) - 내가 직접 만든 요소랑 원본 파일 목록 - 내가 내린 결정 로그 (몇 시에 뭘 골랐고 뭘 바꿨는지) - 모든 파일 해시랑 시간 기록 마지막으로 DistroKid AI 공시란에 그대로 복붙할 문장 써줘. ⚠️ 과장하지 말고 사실 그대로.
