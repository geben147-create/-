# 46컷 배분표 — 8분 30초

컷 수는 잉카편 실측 밀도(§SPEC_FINAL 4)를 구간 성격에 맞춰 배분했다.
전체 평균을 맞추지 않는다. **정보형에서 올리고 정서형에서 내린다.**

## 왜 46컷인가

| 실측 | 값 |
|---|---|
| 장면 길이 중앙값 | 11.9초 |
| 전환 빈도 | 3.64회/분 (누락 보정 5.9) |
| 카메라 속도 | 0.1초당 화면폭 0.6% — 거의 정지 |

510초 ÷ 11.9초 ≈ 43. 구간별 밀도 적용 시 **46컷**.

## ⚠️ 영상 클립으로 510초를 채우지 않는다

무료 영상은 **5초가 상한**인데 장면 하나는 **11.9초**다. 클립으로는 못 채운다.
그리고 원본 채널도 상당수가 **정지 이미지 + 초저속 켄번즈**다 —
보고서 §7-1 이 그렇게 적고 있다:

> "정지 이미지 + 켄번즈"와 "AI 영상 클립"의 경계가 흐려지는 지점을 정확히 노린 속도다.

따라서 조립은 이렇게 한다:

```
기본       배경 이미지 + 편집에서 초저속 켄번즈 (5초에 화면폭 30% 이동)
통과 전환   생성한 5초 영상 클립 (전체의 25.4% 지점에만)
하드컷/디졸브  이미지끼리 편집에서 직접 연결
```

실측 전환 유형 배분: 하드컷 52.1% · 크로스디졸브 18.3% · 통과전환 25.4% · 앵글전환 4.2%
→ 46컷 중 **영상 클립이 필요한 곳은 약 12곳.** 이미 15편 있으므로 충분하다.

## 조립 규칙

1. 이미지 1장 = 장면 1개 = 약 11초. 편집에서 **초저속 켄번즈**를 건다
2. 켄번즈 속도: 11초에 화면폭 **약 66%** 이동 (실측 0.6%/0.1초)
3. **한 컷에 무브 하나.** 팬이면 팬만, 줌이면 줌만
4. 기본 무브는 **수평 팬** (실크로드 주제가 "길"이므로).
   잉카편 기본값인 하강 틸트는 보조로
5. 통과 전환 지점에만 생성한 5초 영상 클립을 끼운다
6. 3초 이상 침묵은 **6~7회**, 공개 직전과 충격 직후에 배치
