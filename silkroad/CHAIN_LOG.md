# 체인 제작 로그 — 실크로드편

전부 **0크레딧**. 이미지 `google/nano-banana-2` 16:9 1K, 영상 `minimax/minimax-h3` 768p 5s.
영상은 모두 `image`(시작) + `imageTail`(종료) 로 앞뒤가 물린다.

## 노드 (확정 매트페인팅 스타일 이미지 10컷)

| # | 장면 | 대본 | 난색 목표 |
|---|---|---|---|
| N1 | 둔황 오아시스 마을 + 미우나이 모녀 | 0:00~0:50 | 28% |
| N2 | 사막폭풍 속 카라반 | 0:50 | 40% |
| N3 | 카라반사라이 (사암 성채) | 1:10 | 48% |
| N4 | 빙하 융빙수 → 오아시스 | 2:00 | 35% |
| N5 | 사마르칸트 돔 도시 | 3:20 | 50% |
| N6 | 아흐라르 관개 영지 | 4:15 | **57% 정점** |
| N7 | 낙타발/트럭바퀴 match cut | 5:05 | 30% |
| N8 | 부산항 컨테이너 터미널 | 5:30 | 15% |
| N9 | 북극 얼음 항로 | 5:50 | **10% 최저** |
| N10 | 편지 회수 (항만 원경) | 8:15 | 57% 회복 |

## 링크 (5초 영상)

| # | 시작 → 끝 | 무브 | 상태 |
|---|---|---|---|
| L1 | N1 → N2 | 마을 이탈 → 봉수대 스쳐 → 먼지벽 진입 | ✅ |
| L2 | N2 → N3 | 먼지벽 관통 → 거점 도착 | ✅ |
| L3 | N3 → N5 | 평원 저공 돌진 (지름길 버전) | ✅ |
| L4 | N4 → N5 | 빙벽 급강하 → 강 따라 질주 | ✅ |
| L5 | N5 → N6 | 수로 따라 이탈 → 영지 전경 | ✅ |
| L6 | N6 → N8 | **상승 → 하강, 600년 시간점프** | ✅ |
| L7 | N8 → N9 | 크레인 사이 이탈 → 바다 → 유빙 도착 | ✅ |
| L8 | N9 → N10 | 얼음 이탈 → 여명 복귀 | ⏳ |

**L1~L7 = 35초가 하나의 연속 이동으로 보인다.**

## 색온도 곡선이 체인에 실려 있다

링크를 순서대로 이으면 난색비율이 저절로 곡선을 그린다:

```
28% → 40% → 48% → 35% → 50% → 57%(정점) → 30% → 15% → 10%(최저) → 57%(회복)
```

잉카편 실측 곡선(황금기 정점 → 몰락 최저 → 유산 회복)과 같은 모양이다.
**컷을 이어붙이는 것만으로 서사 곡선이 구현된다.**

## 재현 방법

```
1. 노드 이미지를 확정 스타일로 생성 (SPEC_FINAL.md §2)
2. 인접한 두 노드로 링크 영상 생성:
   image = 앞 노드 URL, imageTail = 뒤 노드 URL
3. 프롬프트는 SPEC_FINAL.md §7 템플릿
4. 링크를 순서대로 이어붙이면 끝
```

컷 지점이 물리적으로 존재하지 않으므로 전환 효과가 필요 없다.
